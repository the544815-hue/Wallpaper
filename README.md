# Tendies Hub

Каталог .tendies (SwiftUI, iOS 17+). Данные берутся из SerStars/Nugget-Wallpapers.

## Собрать .ipa без Mac
1. Создай репозиторий на GitHub и загрузи туда все файлы из архива.
   Если папки `.github` не видно (на телефоне) — Add file → Create new file,
   имя `.github/workflows/build.yml`, вставь текст из `build-workflow.txt`.
2. Actions → Build IPA → Run workflow.
3. Через несколько минут скачай артефакт `TendiesHub-ipa` (внутри TendiesHub.ipa).
4. Поставь через Sideloadly / AltStore / SideStore (подпишут твоим Apple ID).

## Как пользоваться
Скачал обои → «Отправить в Pocket Poster» → выбери Pocket Poster (или Placard).
Приложение само обои не устанавливает — только ищет, скачивает и передаёт файл.
